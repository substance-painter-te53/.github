## Texturing Overview

Substance Painter lets artists paint directly onto 3D meshes in real time, seeing physically based results update instantly under studio lighting. Its layer stack, masks, and generators make it possible to build complex surfaces without permanently altering earlier work.

The application ships with smart materials and smart masks that adapt to a model's geometry, automatically placing wear on edges and grime in crevices. This dramatically speeds up the creation of believable, story-rich surfaces.

With baking tools, a huge material library, and export presets for every major engine and renderer, Substance Painter has become the default texturing hub across games, film, and design pipelines.

## Getting Started Playbook

Create a new project, import your mesh with a UV layout, and bake the mesh maps so generators and masks have the data they need. Choose a resolution and set your project's shader to match the target renderer.

Drop a smart material onto a texture set, refine it with masks and generators, and hand-paint unique details on top. When the look is final, use an export preset to output packed texture maps for your engine or render pipeline.

## Everyday Use

Artists routinely stack base materials, add procedural wear, and hand-paint focal details, checking results live under different HDRIs before exporting channel-packed maps ready for real-time or offline rendering.
